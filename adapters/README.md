# Adapters

Adapter chỉ mô tả cách đóng gói/nạp content chuẩn vào một môi trường. Adapter **không được**:

- trở thành source of truth cho curriculum/mapping;
- sửa, rút gọn làm đổi nghĩa hoặc thêm rule giáo dục riêng;
- phụ thuộc ngầm vào một nhà cung cấp khi generic contract không yêu cầu.

Phase 1 cung cấp generic adapter hoàn chỉnh và ghi chú tối thiểu cho ChatGPT/Codex.
