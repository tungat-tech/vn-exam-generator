# GPTs bundle: Toán lớp 2 VN 2026–2027

Chạy `scripts/build-chatgpt-math-grade-2.ps1` để sinh bundle trong `dist/chatgpt/math-grade-2-v0.1.0-beta.1/`.

Trong GPT Builder:

- Name: `Toán lớp 2 VN 2026–2027`
- Description: `Tạo phiếu luyện tập và đề ôn tập Toán lớp 2 theo Chương trình GDPT và SGK Kết nối tri thức. Bản beta, cần người lớn rà soát trước khi sử dụng.`
- Instructions: nội dung file `instructions.md`
- Knowledge: tải `knowledge-rules.md` và `knowledge-mapping.md`
- Conversation starters: copy từng dòng file `conversation-starters.txt`
- Web search: tắt mặc định để tránh tự thay đổi curriculum
- Canvas: **bật để hiện bản xem trước và nút Download**
- Code Interpreter & Data Analysis: tùy chọn, chỉ làm fallback sau khi người dùng chọn PDF hoặc DOCX

Conversation starters:

- `Ra đề ôn tập Toán 2 cả năm, 35 phút, có đáp án.`
- `Tạo phiếu luyện Bài 1–3, 15 phút.`
- `Tạo 12 câu luyện bảng nhân và bảng chia 2, 5.`
- `Con đang sai phép trừ có nhớ. Tạo bài luyện vừa sức.`

Không upload toàn bộ repository hoặc fixture vào Knowledge.
