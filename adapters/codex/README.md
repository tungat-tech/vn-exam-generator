# Codex adapter

Cho Codex đọc `subjects/math/grade-3/skill.md`, sau đó các reference được chỉ ra trong workflow và `adapters/generic/manifest.yaml`. Module này cố ý không cài vào thư mục skill cá nhân trong phase 1; repository là nguồn review/versioning.

Không thêm instruction giáo dục chỉ có ở adapter. Nếu về sau đóng gói thành skill cài đặt được, sinh package từ các file chuẩn và kiểm tra package không làm đổi nghĩa.
